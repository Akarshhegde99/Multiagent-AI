# MultiAgent AI 🚀

MultiAgent AI is a smart, modular system for analyzing CSV files with:
- Automated data processing
- Interactive visualizations
- AI-generated insights (via Groq API)
- Production-ready Streamlit UI

## 🔧 Features
- MultiAgent architecture
- Groq AI integration
- Beautiful Streamlit dashboard

```bash
git clone https://github.com/your-repo/multiagent_ai.git
